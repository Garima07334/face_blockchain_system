# Face Identification & Blockchain Verification Pipeline

A pipeline for face identification and blockchain verification.

## Structure
- `app.py`: Entry point for the application.
- `pipeline.py`: Main processing pipeline.
- `core/`: Core modules for face detection, web search, hashing, and blockchain interactions.
- `contracts/`: Solidity smart contracts.
- `tests/`: Automated unit tests.
- `sample_data/`: Sample test datasets.
